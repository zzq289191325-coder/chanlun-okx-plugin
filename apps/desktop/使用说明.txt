Chanlun Quant Trading Desktop 使用说明
=======================================

版本：V1.1 Desktop Lab

启动：
1. 解压整个便携包，不能只复制单个 exe。
2. 双击“Chanlun Quant Trading Desktop.exe”。
3. 软件默认且当前仅启用 PAPER 本地模拟模式：激进短线与基本面长线各自独立 1000U。

当前功能：
- 查看本地数据库、回测和多周期结构研究状态。
- 管理两套资金和仓位完全分开的策略账本：激进短线 1000U、基本面长线 1000U。
- 激进短线单笔上限 120U、总敞口 300U、最低目标盈亏比 2:1；软件运行且本地数据可用时，以每小时至少一笔本地研究试错为频率目标。
- 基本面长线单笔上限 250U、总敞口 500U、最低目标盈亏比 3:1，仅允许本地开多研究且不自动开仓。
- 可分别查看、下本地模拟单、平本地仓和重置各自账本，不会互相占用资金。
- 所有 PAPER 仓位均保存在本地研究环境，不连接 OKX 账户。

安全说明：
- DEMO 与 LIVE 默认锁定，当前构建禁止发送、撤销或修改任何 OKX 订单。
- 软件不包含 API Key、Secret 或 Passphrase。
- 禁止使用带提现权限的 API Key。
- Chrome 插件仍只负责行情结构展示，不读取账户凭证，也不调用交易接口。
- 自动频率仅在软件运行时有效；断网、缺少已收盘 15 分钟数据或触发风控时会暂停并显示未达标，不会绕过风控或伪造成交。

研究声明：
本软件仅用于量化研究和本地模拟，不构成投资建议。所有“候选1/2/3买卖”均为研究标签。

项目内开发启动：pnpm desktop:dev
完整检查：pnpm typecheck、pnpm test、pnpm build、pnpm research:test
