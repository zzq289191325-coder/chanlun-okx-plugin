OKX Chanlun Visualizer Plugin V1.1 Multi-Timeframe Research

一、安装
1. 解压收到的 ZIP 文件。
2. 在 Chrome 地址栏打开 chrome://extensions/。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的文件夹；该文件夹根目录应直接看到 manifest.json。
6. 打开或刷新 OKX / 欧意合约交易页面。

二、使用
- 插件会自动识别当前 OKX 页面标的，并在“主图”模式下自动跟随。
- Alt+C：显示或隐藏插件。
- 周期：主要分析 1D、4H、1H、30M、15M。
- 顶底、结构、点位、裸K：控制图层显示；顶底默认关闭。
- 多周期缠论分析：显示周期结构、WAIT/WATCH/PASS、候选区域与风险收益比。
- 15/30M 区间套：验证 30M 候选与之后出现的 15M 确认是否同向、在结构区间内且未过期。
- 本地新闻影响：在“设置”中每行录入一条新闻；未来事件可写成“2026-08-22 20:00 | FOMC 利率决议”。
- 新闻文本只保存在本机，不自动联网抓取，不读取任何 OKX 账户数据。
- 吸附模式下分析面板默认折叠，避免遮挡 OKX K 线和关键控件。

三、重要边界
- 只使用 OKX 官方公共行情，不读取、不保存、不请求 API Key。
- 不会点击或操作 OKX 买卖按钮，不会提交真实盘或 OKX 模拟盘订单。
- 所有“候选买/候选卖”和 LONG/SHORT 状态均为结构分析标签，不构成投资建议。
- V1.1 不包含真实交易或 OKX 模拟盘下单功能；所有相关内容仅为本地研究或模拟记录。
- 如果无法连接 OKX 原生 TradingView 图表 API，插件会暂停吸附绘图并提示，不绘制假匹配覆盖层。

四、常见问题
- 没有显示：刷新 OKX 页面，确认插件已启用，并按 Alt+C。
- 标的不对：点击“主图”恢复自动跟随，再切换 OKX 页面标的。
- 吸附暂停：切换到 OKX TradingView 图表模式；若原生 API 仍不可用，保持暂停是安全设计。
- 更新版本：在 chrome://extensions/ 中删除旧版或点击刷新，再重新选择新版解压目录。
